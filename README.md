# Cybersecurity Notes

My personal study notes while teaching myself cybersecurity. Everything here is written in my own words from what I learn and practice.

> Self-taught | Learning in public | Updated regularly

## How this repo is organized

Each folder is a topic. Each topic has its own `README.md` (an index) and one note file per subject.

| Topic | What's inside | Status |
| :-- | :-- | :-- |
| [Linux](linux/) | Commands, permissions, users, processes | In progress |
| [Networking](networking/) | OSI, IP, TCP/UDP, ports and protocols | In progress |
| [Python for Security](python/) | Notes and small security scripts | Planned |
| [Cryptography](cryptography/) | Hashing, encoding, classical ciphers | Planned |
| [Web Security](web-security/) | OWASP Top 10, common vulnerabilities | Planned |
| [CTF Write-ups](ctf-writeups/) | Challenge walkthroughs and lessons | Planned |
| [Resources](resources/) | Courses, books, tools I use | Ongoing |

## Note format

Every note follows the same structure (see [`_template.md`](_template.md)):

1. What it is
2. How it works
3. Example I ran
4. Mistakes and surprises
5. Security angle
